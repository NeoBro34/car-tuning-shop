# PRD - Car Tuning Shop

## Product Overview

Car Tuning Shop is an online store for selling car tuning parts and accessories.

## Target Users

- Car owners
- Tuning enthusiasts
- Auto repair shops
- Car accessory sellers

## Main Features

### Customer Features

- Register / Login
- Browse products
- Search products
- Filter by category
- Filter by brand
- Filter by car model
- View product details
- Add to cart
- Place order

### Admin Features

- Add product
- Edit product
- Delete product
- Upload product images
- Manage categories
- Manage brands
- Manage orders
- Manage users

## Product Fields

Each product should have:

- name
- description
- price
- discount price
- stock quantity
- category
- brand
- compatible car models
- images
- SKU
- status
